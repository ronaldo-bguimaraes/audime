# Cycle: Frontend MVP

**Date:** 2026-06-30 02:32

## Summary
Implementation of the Audime frontend MVP (React + TypeScript + Vite).

## What was done
- Passwordless login screen (email → code → JWT)
- Dashboard with invoice list
- NFC-e upload via QR Code URL
- Invoice details with items
- SPA navigation with react-router v8
- Route protection (authenticated vs public)
- CSS Modules with responsive design
- Vite proxy for backend in dev

## Decisions Made
- react-router v8 (unified package) in declarative mode
- Native fetch with centralized wrapper in `api/client.ts`
- CSS Modules (zero dep, Vite native)
- JWT in localStorage (accepted for MVP)
- AuthProvider + useAuth (Context API)

## Lessons
- Verify react-router v8 compatibility before importing [MEMORY]
- Handle 401 on auth endpoints separately from protected ones [EXECUTION]
- Use ref for fetcher in fetch hooks to avoid stale closures [EXECUTION]
- CSS Modules with Vite is zero-config and solves scoping [EXECUTION]
