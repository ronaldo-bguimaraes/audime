# Records

Histórico de features e decisões: o que foi entregue, com qual evidência, e por quê.

- Um arquivo por feature/entrega: `YYYY-MM-DD-<assunto>.md`.
- Registre o **resultado verificável** (comando + saída), não a intenção.
- Decisão que gera trabalho futuro vira uma spec nova em `specs/`, não uma nota solta.

`2026-07-29-sprint-planning.md` é o último planejamento do processo anterior
(squad de agentes, aposentado em 2026-10) e guarda a pesquisa de OAuth do #3 —
use como insumo para `/speckit.specify`, não como plano vigente.
